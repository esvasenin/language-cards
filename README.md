🧠 Language Cards

Language Cards — это простой обучающий веб-сервис на Django для изучения иностранных слов. Пользователь может добавлять карточки с переводами и изображениями, просматривать их и тренироваться в режиме практики.

🚀 Функции

📥 Добавление новых карточек с переводом и картинкой

📋 Просмотр всех карточек

🧩 Режим практики — случайные карточки с переводом по нажатию

🖼️ Поддержка загрузки изображений (Pillow)

🎨 Bootstrap-стили для удобного интерфейса

🛠️ Установка и запуск

# 1. Клонируем проект

git clone https://github.com/esvasenin/language-cards.git

cd language-cards

# 2. Создаём и активируем виртуальное окружение

python -m venv venv

source venv/bin/activate   # (Linux/macOS)

venv\Scripts\activate      # (Windows)

# 3. Устанавливаем зависимости

pip install django pillow

# 4. Применяем миграции и запускаем сервер

python manage.py makemigrations

python manage.py migrate

python manage.py runserver

Открой в браузере: http://127.0.0.1:8000/

💡 Пример использования

Перейди на главную страницу

Нажми «Добавить карточку», укажи слово, перевод и (опционально) картинку

В режиме практики случайное слово будет показано без перевода — проверь себя!
